# Finnair Virtual

An independent, fan-made virtual airline for flight simulation (Infinite Flight),
inspired by **Finnair** — Nordic design, hospitality and smooth travel. Built with
Next.js 16, React 19 and Tailwind CSS v4.

> Finnair Virtual is not affiliated with, endorsed by, or connected to Finnair Plc,
> the oneworld alliance, or Infinite Flight.

## Features

A full virtual-airline platform centred on the **Crew Center** (`/crew`):

- **Crew Center** — staff dashboard with Applications, Pilots roster, PIREP review,
  live Flights, Stats/leaderboard, LOA management, Reports and News admin.
- **Pilot hub** — file PIREPs (with one-click autofill from your IF logbook),
  flight deck, rank progression and leaderboard.
- **Public site** — home, about, staff, ranks, operations/network, news, codeshares,
  fleet explorer and a live flight map.
- **Theming** — light (default, Nordic-airy) and a deep Twilight-Blue dark mode,
  driven entirely by CSS design tokens.

## Brand

| Token | Colour | Hex |
| --- | --- | --- |
| Twilight Blue (primary) | navy | `#0B1560` |
| Pure White | white | `#FFFFFF` |
| Plum Purple (accent) | plum | `#7E1F89` |

Ranks follow a Nordic "northern sky" theme — Aurora → Polaris → … → Louhi, with
*Taimi* as the mentorship rank. Typeface: Inter (standing in for Finnair Sans).

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The app runs out-of-the-box in **demo mode** with a seeded roster. It goes live the
moment you configure the optional integrations:

- `DATABASE_URL` — Neon Postgres for pilots + PIREPs (otherwise in-memory demo store).
- `IF_API_KEY` — Infinite Flight Live API for the live map and logbook autofill.
- Discord OAuth / bot env vars for pilot login and the Discord integration.

## Data

- `src/lib/data.ts` — single source of truth (brand, fleet, hubs, ranks, staff, …).
- `src/lib/routes.ts` — route network, generated by `scripts/gen-finnair-routes.mjs`.
- `src/lib/seed.ts` — demo pilot roster.
